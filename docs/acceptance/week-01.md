## Inspected sources

Sources were opened and relevant content inspected during this revision. These are review references, not added required homework.

- [MDN: What is a web server?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_web_server): hardware/software distinction and static/dynamic content. Required selection remains 8 minutes.
- [Node HTTP](https://nodejs.org/api/http.html#httpcreateserveroptions-requestlistener): `createServer`, request/response example, status/header and `listen`. Required selection remains 10 minutes. This URL tracks current Node documentation; only the stable introductory methods are assigned, not newer API features.
- [React createRoot](https://react.dev/reference/react-dom/client/createRoot): browser DOM rendering and “Rendering an app fully built with React.” Required selection remains 7 minutes.
- [Node 22 process](https://nodejs.org/docs/latest-v22.x/api/process.html): PID, uptime and RSS definition; optional for students.
- [Azure core architecture module](https://learn.microsoft.com/en-us/training/modules/describe-core-architectural-components-of-azure/) and its [physical infrastructure unit](https://learn.microsoft.com/en-us/training/modules/describe-core-architectural-components-of-azure/5-describe-azure-physical-infrastructure): data-center power, cooling and networking; optional preview. No regional failover promise is derived from the module.
- [Docker: containers versus VMs](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-a-container/): process isolation, shared kernel and VM/container combination.
- [curl manual](https://curl.se/docs/manpage.html): `-i` includes response headers; the actual Windows invocation is recorded in the transcript.
- [Fetch standard: port blocking](https://fetch.spec.whatwg.org/#port-blocking): port 4190 is blocked. This explains the corrected fixture failure below.

An attempted KVM overview URL could not be fetched and is **not** treated as verified or assigned. This does not remove the reviewed Docker VM/container reference. Optional platform variants were not falsely labeled executed.
